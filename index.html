사용법
• 상단의 CUB 또는 FAB를 선택하세요.
• 상단 편집 버튼으로 편집 모드에 들어간 뒤 층 버튼을 누르면 해당 층 이름을 수정할 수 있습니다.
• 일반 모드에서는 층 버튼을 누르면 해당 층으로 이동합니다.
• 층 버튼 오른쪽의 ＋ 버튼을 누르면 CUB와 FAB에 새 층을 각각 추가할 수 있습니다.
• 추가한 층은 해당 층 전용 도면, 밝기와 BP 배치를 별도로 저장합니다.
• 왼쪽 BP명을 누르면 현재 도면 중앙에 사각 영역이 생성됩니다.
• 사각 영역을 한 번 눌러 선택한 뒤, 영역 내부를 끌어 원하는 위치로 이동하세요.
• BP 이동·크기 조절·삭제는 편집 비밀번호를 입력한 뒤에만 가능합니다.
• 전체 BP 편집은 상단 편집 버튼을 누르고 비밀번호를 입력하세요. 선택한 BP에 조절점과 X 삭제 버튼이 표시됩니다.
• 스마트폰에서는 BP를 약 1초간 길게 누른 뒤 비밀번호를 입력하면 해당 BP만 편집할 수 있습니다. 전체 편집은 상단 편집 버튼을 사용하세요.
• 도면 업로드 버튼에서 PNG, JPG 또는 JPEG 도면을 선택할 수 있습니다. PC와 스마트폰 모두 지원합니다.
• 도면 밝기 슬라이더로 현재 층 도면의 표시 강도를 0~100%로 조정할 수 있습니다.
• PC에서는 마우스 휠, 스마트폰에서는 ＋/－ 버튼으로 도면을 확대·축소하세요.
